# P1 condition addendum

You have the same raw source snapshot and source tools as B0, plus read-only tools over a precomputed source-relation index. The index contains syntactic/navigation candidates (such as declarations, calls, containment, and selected file/symbol hints); it does not prove runtime behavior, complete data flow, reachability, or exploitability. Use it to navigate, then verify every candidate and relevant edge against source text. Do not treat an index label or edge as a vulnerability verdict.

Before searching, call `get_relation_scope` and account for omitted or unparsed files and unsupported analyses in your coverage statement. Do not claim that an unreported code area was reviewed merely because the index has no matching record there.
